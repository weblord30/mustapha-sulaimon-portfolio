    How It Matches The Role

    Your requirements, in working code.

    Semantic, Accessible HTML

    Landmarks, a real table with caption and headers, ARIA switch and tab roles, live regions for new orders, a skip link and visible focus. Every control works with the keyboard alone.

    Modular JavaScript

    Small modules for state, rendering, the chart and the live feed. A single render() keeps the KPIs, table and stock in sync after every action.

    Motion With Purpose

    CSS transitions show what changed: new orders slide in, KPIs pulse, stock meters fill. Everything respects reduced motion settings.

    Speed On Real Networks

    One small file with an inline SVG chart and no framework, so it loads fast on Nigerian mobile data. It's responsive down to small phones, with iPhone safe areas handled.
